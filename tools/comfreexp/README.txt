COMFreeXP
=========

GUI-утилита для Windows XP для проверки и сброса выбранного COM-порта.

ВАЖНО: Windows XP поддерживается только Go 1.10.x. Последняя официальная
версия Go с поддержкой Windows XP — Go 1.10.8. Поэтому этот инструмент
лежит внутри репозитория МодбасШлюз, но собирается ОТДЕЛЬНЫМ старым
toolchain. Основной mbgw.exe продолжает собираться Go 1.20.14.

Рекомендуемая сборка на рабочем Windows-ПК:
  set GOOS=windows
  set GOARCH=386
  go1.10.8 build -ldflags="-H windowsgui -s -w" -o bin\COMFreeXP.exe .\tools\comfreexp

Почему GOARCH=386: максимальная совместимость со старыми Windows XP.

Что делает кнопка «Проверить»:
  - пытается открыть COM эксклюзивно;
  - если открывается — порт свободен;
  - если ERROR_ACCESS_DENIED/SHARING_VIOLATION — порт занят или запрещён;
  - отличает отсутствующий порт и ошибки драйвера.

Что делает «Освободить / сбросить»:
  1. если порт открывается — очищает RX/TX, сбрасывает DTR/RTS и закрывает handle;
  2. находит PnP-устройство, которому принадлежит COM;
  3. выполняет Disable -> Enable через SetupAPI;
  4. повторно проверяет, открывается ли COM.

Утилита НЕ завершает процесс, который держит COM. Если программа опроса
работает и автоматически переоткрывает порт, после сброса он снова может
стать занят. Для PnP Disable/Enable нужны права администратора.
